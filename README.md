# Gigio Automations

Automazioni personali di MarcoMan gestite da Gigio (supervisore tecnico BitsLegacy).
Girano su GitHub Actions — indipendenti dal PC locale.

## Workflows attivi

| Nome | Frequenza | Canale |
|---|---|---|
| Buongiorno MarcoMan | Ogni giorno alle 9:00 | Telegram |

## Secrets richiesti su GitHub

Aggiungere questi secrets nelle impostazioni del repo (Settings > Secrets > Actions):

| Secret | Valore |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Token del bot Bits Legacy Gigio Bot |
| `TELEGRAM_CHAT_ID` | Chat ID di MarcoMan |
